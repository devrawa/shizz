What’s inside

  • Android-focused React + TypeScript interface
  • Python streaming, model and research backend
  • Go public-web reader + Rust secret-pattern scanner
  • Two voice paths: Sorani turns and Realtime WebRTC
  • Scoped defensive tools and unsent work proposals
  • Bash setup/build/test scripts and detailed guides

Honest boundaries

Demo chat is prewritten and clearly labelled. Provider integrations need credentials and evaluation. Sorani fluency, response speed and income are not guaranteed.

The two reference files were unavailable and were not reviewed. Rust was chosen from your Rust/C++ alternative.

01

Try it on a computer

Install Python 3.11+ and Node.js 20+. Go/Rust are optional helpers. On Linux/macOS/WSL, from this folder:

bash scripts/bootstrap.sh --dev
bash scripts/dev.sh

Then open http://localhost:5173. The default local demo does not call paid services.

02

Connect real intelligence

Read SETUP.md. Configure server-only provider keys, private owner token, selected model and HTTPS deployment. Enter only your backend URL and device token in the app.

03

Build for your phone

Read ANDROID.md. Use JDK 21, Android Studio + SDK 35, or review the included on-demand CI build recipe. No Gradle/device build was performed for this delivery.

If you only have a phone, a developer or build service must compile the APK and host the backend. Do not paste your provider keys into public messages or app source.

04

Evaluate Sorani before relying on it

Use the native-speaker test plan. Recognition, understanding, pronunciation and latency are separate things to measure. Realtime Sorani remains experimental.
